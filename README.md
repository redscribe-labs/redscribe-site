# RedScribe

The marketing site for [RedScribe](https://github.com/redscribe-labs/redscribe), self-hosted
engagement, finding, checklist, and report management for penetration
testing teams. Kept as its own isolated project, separate from both the app
repo and the [documentation site](https://github.com/redscribe-labs/redscribe-docs), so each has
its own history and its own deploy target.

## Structure

```
redscribe-site/
├── site-src/     # EDIT HERE, a plain Astro project (no framework beyond Astro itself)
└── docs/         # BUILT OUTPUT, static HTML generated by `npm run build`, committed
```

Same two-directory pattern as `redscribe-docs`. `site-src/` is hand-written
Astro plus custom CSS, no component library, no Starlight, since this is a
one-page marketing site with its own design rather than a documentation
tree. `docs/` is generated, not hand edited, and is what GitHub Pages
serves.

## Building

Requires **Node.js ≥22.12.0**. If your system Node is too old, grab a
standalone build rather than changing anything system-wide:

```sh
mkdir -p .tools && cd .tools
curl -fsSL -o node.tar.xz "https://nodejs.org/dist/v22.23.2/node-v22.23.2-linux-x64.tar.xz"
tar -xf node.tar.xz && mv node-v22.23.2-linux-x64 node22 && rm node.tar.xz
cd ..
export PATH="$PWD/.tools/node22/bin:$PATH"
```

Then, from `site-src/`:

```sh
cd site-src
npm install      # first time only
npm run build     # writes into ../docs
npm run preview   # serve the build locally to check it before committing
```

## Design

Every color is a real token from the app's own `COLOR_SCHEME.md`, and both
typefaces (Plus Jakarta Sans, JetBrains Mono) are the app's own self-hosted
fonts, copied in under `site-src/public/fonts/`. The logo is an original mark: three
redaction bars of decreasing width, the top one in the app's signal green,
meant to read as "a report with one visible finding" without being a
literal letterform. See `site-src/src/components/` for the mark's SVG and
`site-src/src/styles/global.css` for the full token set.

## Publishing to GitHub Pages

Same setup as `redscribe-docs`, and the same two gotchas apply here too
(`base`/`site` in `astro.config.mjs` matching the real Pages URL, and
`docs/.nojekyll` existing so GitHub Pages doesn't strip Astro's `_astro/`
asset folder). Both are already handled in this repo from the start.

`Settings → Pages`, Source: Deploy from a branch, branch `main`, folder
`/docs`.
